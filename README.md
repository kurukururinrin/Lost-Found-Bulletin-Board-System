# Lost-Found-Bulletin-Board-System

These are all the files for our ITMP project. If you want to access the website without downloading all the project files, you can visit it through the following link:

**Website:** https://lostandfounditmp.42web.io

However, please be aware of the following limitations:

## 1. Website Hosting and Security Warnings

Our website is hosted on InfinityFree, a free PHP hosting service. Unlike a website hosted on a dedicated server, a free hosting service may use shared server resources to host multiple websites. This means that our website has limited control over the server environment and its security configuration.

As a result, we cannot fully control how external security services evaluate our website. If Google displays a security warning, it does not automatically mean that our website contains malicious code. However, the warning should not be ignored, as it may also indicate a genuine security issue that requires investigation.

I have submitted a report to Google requesting a review of our website. However, the warning may remain until Google completes its review and confirms that the issue has been resolved.

## 2. AI Matching Functionality

The website's PHP-based functions have been deployed to the online hosting environment. Therefore, all the webpages and their database-related functions should work as intended.

However, the AI image-matching model has not been deployed to the server due to the large file size of the CLIP model.

Therefore, the match webpage can still be accessed and viewed, but its backend AI matching function may not work as expected.
